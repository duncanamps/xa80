# xa80 Opcode Compiler Files

This is the folder for the opcode compiler.
See the source folder and the <code>*.opcode</code> files for the details of the structure.

The <code>lac</code> folder contains the grammar for the opcode compiler
<code>op_comp.exe</code> is the opcode compiler and just takes a source filename and will output a .opcode.bin file

<code>compile.bat</code> will compile all the source files

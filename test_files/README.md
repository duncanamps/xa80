# xa80 Test Files

A group of test files for the xa80 cross assembler.

<table>
  <tr><td><b>Folder</b></td><td><b>Contents</b></td></tr>
  <tr><td valign="top">8080</td><td valign="top">Contains test files containing 8080 code. Also includes CP/M code for the BDOS (Basic Disk Operation System) and CCP (Console Command Processor). It does not include any BIOS files as these would be hardware specific.</td></tr>
  <tr><td valign="top">calibration</td><td valign="top">A suite of calibration files for testing that everything goes correctly, and also for checking that things go wrong when they are supposed to.</td></tr>
  <tr><td valign="top">debug</td><td valign="top">A rough collection of files which were used for debugging specific issues. Their value, ongoing, is limited.</td></tr>
  <tr><td valign="top">z80</td><td valign="top">A collection of Z80 source files. Some of this is useful, some is definitely work in progress.</td></tr>
</table>
